# Minhas skills do Claude

Skills em `.claude/skills/`. Elas ficam disponíveis em qualquer sessão do Claude Code (nuvem, celular ou computador) aberta **com este repositório**.

| Skill | Para quê |
|---|---|
| `video-podcast-maker` | Vídeo narrado completo (pesquisa → roteiro → voz → Remotion → 4K) |
| `video-podcast-maker-nano` | Versão mínima de vídeo narrado |

Voz grátis: Edge TTS (`pip install edge-tts`), vozes `pt-BR-FranciscaNeural` / `pt-BR-AntonioNeural`.
Requisitos: `python3`, `ffmpeg`, `node`.

Origem: [Agents365-ai/video-podcast-maker](https://github.com/Agents365-ai/video-podcast-maker)

`instalar-obsidian.ps1`: instalador do hook que salva as conversas do Claude Code no Obsidian (Windows).
